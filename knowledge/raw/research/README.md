# Research sources

Empty for now. This directory holds raw, immutable inputs from *outside* this repository and
outside direct product-owner instructions — competitive research, library evaluations,
external API docs saved for reference, etc. — that a wiki page might cite.

Add files here as `<topic>-<yyyy-mm-dd>.md` and cite them from a `knowledge/wiki/` page's
`sources:` frontmatter. Do not put session summaries here — those belong in
`knowledge/raw/sessions/`. See `docs/LLM_WIKI.md`.
